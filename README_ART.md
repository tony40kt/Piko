
📄 《奇妙貼貼島》第一階段美術外包需求單


1. 專案基本規格

• 目標受眾： 2-6 歲幼兒教育應用，風格需繽紛、童趣、高飽和度、粗線條（美式向量或日系 Q 版）。
• 螢幕方向： 固定 橫螢幕操作 (Landscape Only)。
• 交付格式： 需提供原始分層檔案（強烈建議使用 Figma 或提供 PSD/AI），以及匯出好的去背透明 PNG 檔 (需包含 @2x 和 @3x)。

2. 第一階段切圖需求清單 (Asset List)

請設計師針對以下項目進行整體視覺風格定調與報價：
• 【A 組：主地圖與場景（核心地基）】
	• 1. 島嶼全景底圖： 包含海洋與島嶼地形。
	• 2. 鎖定烏雲圖層 (共 4 張)： 需能完美重疊在底圖海灘、森林、碼頭、雲天上方的半透明灰色雲霧圖，每張圖中央需帶有一個可愛的鎖頭標誌。
	• 3. 大屋基地外觀： 預設彩色的雙層小屋，與底圖完美重合。
	• 4. 大屋室內剖面圖 (1 張)： 點擊大屋放大進入的室內場景（包含兩層樓牆壁與地板，不帶任何家具）。
• 【B 組：核心 UI 元件（AI 程式排版用）】
	• 1. 貼紙欄彈出鈕： 放在右下角的半透明箭頭按鈕。
	• 2. 貼紙欄背景底圖： 水平彈出的半透明長條工具欄底圖。
	• 3. 虛擬方向鍵 (D-Pad)： 迷宮使用的上、下、左、右方向鍵按鈕。
	• 4. 學習幣圖示： 一枚亮晶晶的卡通金幣。
	• 5. 垃圾桶圖示： 放置在貼紙欄旁邊的可愛垃圾桶。
• 【C 組：試做型基礎貼紙（風格定調用，各類別抽 1-2 個）】
	• 備註：所有貼紙邊緣皆需帶有一圈白邊，做出實體貼紙的剪裁感。
	• 家具類： 可愛沙發 x1、單人床 x1。
	• 動物類： 小狗 x1、螃蟹 x1。
	• 裝飾類： 彩虹 x1、椰子樹 x1。

💡 與外包溝通時的「發包備忘錄」

當你把這份清單發給設計師時，可以補充說明：「這是我應用的第一階段核心架構。若這批圖的風格與切圖精準度符合預期，第二階段將會持續追加約 30-50 張的常規貼紙，以及 3 張高難度的『每日挑戰限定特殊華麗貼紙』長期合作。」 這樣通常能吸引到更有經驗、更穩定的設計師或團隊來接單！
