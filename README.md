# 奇妙貼貼島 (Magic Sticker Island) - 專案開發與架構規格白皮書

本文件為《奇妙貼貼島》的終極開發指南。本專案專為 **2-6 歲兒童** 設計，結合「多語言語文與數學題庫」與「島嶼/大屋貼紙佈置建造」的跨平台教育 App。
不論是新的開發者加入、或是交由 GitHub AI 協作，**只需閱讀本手冊即可完全理解所有商業邏輯、核心算法、付費牆架構並隨時接手專案。**

---

## 🛠 1. 技術框架與打包限制

- **主要框架：** Flutter (Dart) 跨平台技術，需同時相容 iOS 與 Android。
- **無 Mac 電打包環境：** 本專案在開發與部署時，嚴禁引入需要本地端 native 配置或 vendor-locked 的 native 第三方套件。必須保持純 Flutter/Dart 架構，以便利用 **GitHub Actions** 或 **Codemagic** 進行 iOS 雲端打包 (`.ipa`)。
- **國際化 (i18n)：** 基於 `flutter_localizations`，所有文本讀取 `assets/json/` 內的語系字典。初始支援：繁體中文 (`zh-TW`)、簡體中文 (`zh-CN`)、英文 (`en`)。架構須保留未來只需擴充 JSON 檔即可免改 Code 新增語言的彈性。

## 💎 2. 商業變現與權限分級 (RevenueCat)

本 App 採用 **Freemium (免費下載 + 應用內訂閱制)**。技術端整合 **RevenueCat (purchases_flutter)**，由全域 `SubscriptionManager` 動態攔截權限。

### 🔓 免費版 (Free Tier) 限制：
1. **多帳戶：** 限制僅能建立 1 個兒童個人檔案。
2. **島嶼地圖：** 僅開放「區域 0 (大屋基地)」。點擊其餘鎖定區域（區域 1~4）時，強制彈出訂閱付費牆（Paywall UI）。
3. **冒險傳送門：** 每日限制挑戰 1 次（不分科目與難度）。
4. **每日挑戰（碼頭）：** 完成挑戰僅能獲得正常獎勵（無雙倍加成），且累積參加解鎖的「限定版特殊貼紙」顯示為鎖定狀態，提示「訂閱解鎖」。

### 💎 訂閱版 (Premium Tier) 權限：
- 解鎖多帳戶管理（無上限）、全地圖區域金幣解鎖、無限次挑戰冒險傳送門、每日挑戰享有 2 倍（Double）學習幣獎勵、可正常領取累積參加的限定特殊貼紙。
*備註：貼紙商店的常規商品不論是否訂閱，一律 100% 全開放供金幣兌換。*

## 👥 3. 多帳戶管理系統 (儿童個人檔案)

- **初次啟動：** 畫面導向「建立個人檔案」視窗（欄位：名字、出生日期 DoB、主語言）。
- **多帳戶控制：** 帳戶資料透過 `SharedPreferences` 持久化儲存。免費用戶嘗試建立第二個帳戶時，攔截並跳出付費牆。
- **啟動路由分流邏輯：**
  - 系統內有 **0 個帳戶**：跳至建立檔案頁面。
  - 系統內有 **1 個帳戶**：自動登入該帳戶，跳過選擇畫面直達主島嶼。
  - 系統內有 **2 個或以上帳戶**：啟動時顯示「選擇帳戶」畫面。
- **設定頁面：** 提供「新增帳戶」與「修改帳戶」按鈕。
- **系統自動分級：** 系統根據當前帳戶的出生日期自動換算年齡，在自選或正常關卡中由系統自動派送題目，免去兒童手動點選年齡。

## 🏝 4. 主畫面：未開墾的島嶼 (UI 與佈局)

- **視覺規格：** 響應式、**固定橫螢幕操作 (Landscape Only)**，單一螢幕大小不可滑動。
- **金幣解鎖烏雲機制：** 地圖採用 `Stack` 疊加圖層。初期地圖有 4 個區塊覆蓋灰色半透明烏雲圖片（帶有鎖頭）。消耗「學習幣」可解鎖。
  - **區域 0 (預設解鎖)：** 大屋基地（點擊可放大進入「大屋室內剖面圖場景」進行貼紙佈置）。
  - **區域 1 (鎖定)：** 奇妙海灘。
  - **區域 2 (鎖定)：** 螢光森林。
  - **區域 3 (鎖定)：** 繽紛碼頭（每日挑戰入口）。
  - **區域 4 (鎖定)：** 夢幻雲天。
- **按鈕觸發：** 右下角放置半透明「箭頭圖案」，點擊從底部彈出半透明背景的水平滾動貼紙工具欄。

## 🧸 5. 貼紙與場景建造系統

- **工具欄欄位：**
  - 欄位 1：最近使用（自動快取並排列最新使用的 10 個貼紙）。
  - 欄位 2：分類貼紙（依家具、動物、裝飾等頁籤分類）。
  - 欄位 3：全部貼紙（無分類網格列表）。
- **拖拽與手勢 (Drag & Drop)：**
  - 貼紙放上場景後，預設固定大小，支援「雙指旋轉」角度。
  - **無限縮放功能 (Pinch to Zoom)：** 欄位內有一個醒目的「一鍵縮放開關」（免付費/免訂閱）。勾選後，全解鎖所有貼紙的雙指縮放功能。
- **刪除機制：** 將貼紙拉到工具欄旁的「垃圾桶圖示」，彈出適合幼兒的確認視窗，確認後刪除。

## 📝 6. 核心題庫與計分演算法 (冒險傳送門)

- **用戶流程：** 冒險傳送門 ➔ 選擇 [語文] 或 [數學] ➔ 選擇模式：
  1. [正常冒險]：系統依帳戶年齡指派題目。
  2. [自選冒險]：自由選擇難度（以每 1 歲為一個階層，共 2-6 歲五個難度階層）。
- **雙語學習 (語文題)：** 語文題共用同一個核心題庫 JSON，選擇「自選語言模式 (預設英文)」時，自動透過翻譯字典轉換為英文出題。數學題則一律自動翻譯成兒童的「主語言」。
- **核心獎勵經濟演算法公式：**
  - 題目完美初始獎勵 = `15 枚學習幣`。
  - 答錯扣分：可重複答錯，但每錯一次扣 `2 枚`。
  - 最低保底：該題獎勵最低降至 `5 枚` 止扣。
  - 難度加成公式：`基礎獎勵 * (1.0 + (當前難度年齡 - 2) * 0.1)` (即 3歲 1.1倍、4歲 1.2倍，以此類推)。
  - **進位邏輯：** 最終學習幣計算結果若含有小數點，**系統必須使用 `ceil()` 自動無條件進位至最新整數**。

## 🎮 7. 獨立遊戲系統 (獨立傳送門)

*註：不列入冒險傳送門與每日挑戰。*
- **遊戲 1：找不同：** 畫面呈現左右/上下對照圖，讀取 (X,Y) 座標判定。2-3 歲需找 3 處；4-6 歲需找 5 處。
- **遊戲 2：簡單迷宮：** 2D 迷宮路徑，畫面上提供 D-Pad 方向鍵（上/下/左/右）控制主角移動，碰牆會被擋住。

## ⚓ 8. 碼頭：每日挑戰核心邏輯

- **運作機制：** 每日午夜 12 點重設，每日限制挑戰 1 次。一經進入挑戰即鎖定，當天無法重複進入該關卡。
- **題目配置：** 依年齡隨機從題庫抽取 3 題。
- **每日挑戰計分法：** 每題基礎獎勵為 **3 枚學習幣**。**答錯該題直接獲得 0 枚。**
- **訂閱加成：** 訂閱用戶最終獲得的總學習幣享有 **2 倍（Double）加成**；免費用戶僅獲得正常計算之代幣。
- **累積參加獎勵（補償機制）：**
  - 採用累積制（如累計參加 5 次、10 次）。**只要點進去並參加即可，不考慮該次的答對率。**
  - 達標時解鎖限定版特殊貼紙。若為免費用戶，貼紙顯示鎖定並提示「訂閱解鎖」；用戶隨時補訂閱即可立即領取。

## 🧪 專案五大階段驗收清單 (Acceptance Criteria)

### 🧱 【階段 1 驗收：多帳戶與骨架】
- [ ] 模擬器手動切換語系至英文、繁中、簡中，確認基礎介面文字自動變更。
- [ ] 刪除 App 重新安裝，確認初次啟動正確跳出「建立個人檔案」畫面。
- [ ] 單一帳戶時重啟 App，確認自動跳過選擇帳戶，直達主頁面。
- [ ] 新增第二個帳戶時，重啟 App 確認顯示「帳戶選擇」畫面。

### 📝 【階段 2 驗收：核心題庫引擎】
- [ ] 測試答錯 1 次得 13 幣；故意答錯 10 次確認具備最低保底 5 幣。
- [ ] 測試高難度加成關卡，確認計算結果含有小數時有自動進位（如 16.5 幣變 17 幣）。
- [ ] 點進每日挑戰後退出，確認當天再次點擊時該關卡為鎖定狀態。
- [ ] 模擬跨天連續參加每日挑戰，確認無論對錯，「累積參加次數計數器」皆有正確累加。

### 🏝 【階段 3 驗收：地圖與貼紙拖拽】
- [ ] 測試同時拖拽 20 個貼紙在畫面上，確認畫面保持流暢不卡頓、不崩潰。
- [ ] 未開啟縮放開關時貼紙只能旋轉；勾選縮放開關後，確認雙指能自由放大縮小。
- [ ] 點選不同貼紙，確認「最近使用」欄位維持最新 10 個且排序正確。
- [ ] 金幣足夠時解鎖區域，確認烏雲消失。重啟 App 後確認該區域維持解鎖狀態。

- [ ] 免費用戶狀態下點擊「建立第二個帳戶」或「解鎖區域 1」，確認有正確跳出付費牆。
- [ ] 免費用戶完成每日挑戰，確認無雙倍獎勵，且累積限定貼紙顯示鎖定。
- [ ] 在 RevenueCat 沙盒環境購買訂閱，確認購買後免費用戶瞬間升級 Premium 狀態，且先前鎖定的特殊貼紙可立即領取。
- [ ] 測試「恢復購買」按鈕，確認能正確抓回已有訂閱。

### 🚀 【階段 5 驗收：小遊戲與最終打包】
- [ ] 實際點擊找不同遊戲，確認圈起位置與圖片相異處完全對齊，無座標偏移。
- [ ] 控制迷宮主角撞牆，確認角色會被擋住，無穿牆 Bug。
